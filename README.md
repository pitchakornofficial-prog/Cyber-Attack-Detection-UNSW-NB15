# Cyber Attack Detection Using Machine Learning

## Research Question

Can machine learning models accurately distinguish normal network
traffic from cyber attacks using the UNSW-NB15 dataset?

## Dataset

UNSW-NB15 Version 5

## Models

- Logistic Regression
- KNN
- Random Forest

## Methods

- Exploratory Data Analysis
- PCA
- Statistical Analysis
- Bias-Variance Analysis
- 5-Fold Cross-Validation

## Results

Random Forest achieved the highest mean F1-score in 5-fold
cross-validation:

F1 = 0.9648 ± 0.0008
